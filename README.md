# Whisper Pro

تطبيق محلي لإنشاء ملفات الترجمة من الفيديو والصوت، واستخراج مسارات الترجمة النصية المضمنة، بواجهة عربية ومحركات متعددة وإعدادات تتغير بحسب المحرك والنموذج.

مشروع **يوسف خالد العربي**. ابدأ بـ[دليل التثبيت والاستخدام خطوة بخطوة](GUIDE_AR.md). وللإبلاغ عن ثغرة، راجع [سياسة الأمان](SECURITY.md).

للتواصل حول المشروع مع يوسف خالد العربي، أرسل رسالة عبر [واتساب ‎+967 718794330](https://wa.me/967718794330).

## التشغيل دون أوامر

نزّل الحزمة المناسبة من **Releases** في GitHub، وفك ضغطها ثم افتح الملف المبين أدناه.

| جهازك | الحزمة | افتح بعد فك الضغط |
|---|---|---|
| Windows x64 | `WhisperPro-Windows-x64.zip` | `WhisperPro.exe` |
| Mac بمعالج Apple Silicon | `WhisperPro-macOS-arm64.tar.gz` | `WhisperPro.app` |
| Mac بمعالج Intel | `WhisperPro-macOS-x64.tar.gz` | `WhisperPro.app` |
| Linux x64 أو ARM64 | `WhisperPro-Linux-x64.tar.gz` أو `WhisperPro-Linux-arm64.tar.gz` | `WhisperPro` |

1. اضغط **الإعداد والتشغيل**. يفحص المشغّل متطلبات النظام أولًا. على Windows، إذا احتجت مكتبة Visual C++، يظهر رابط Microsoft لتثبيتها ثم تعيد الضغط على الزر. [المتطلب لدى CTranslate2](https://opennmt.net/CTranslate2/installation.html) · [تنزيلات Microsoft الرسمية](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).
2. وافق على الإعداد واترك الإنترنت متصلًا. يُجهز المشغّل بيئة Python 3.12 ويثبّت المكتبات المطابقة لقفل التبعيات، ثم يفتح التطبيق تلقائيًا في المتصفح. قد تستغرق أول مرة عدة دقائق.
3. في المرات التالية اضغط **تشغيل**. تُعاد الاستفادة من البيئة الموجودة. إذا توقف التجهيز، تظهر تفاصيل الخطأ ويمكنك إعادة المحاولة من الزر نفسه. يتطلب تغيير مجموعة التبعيات في إصدار جديد تأكيد تجهيز ذلك الإصدار.

تتطلب الحزمة الرسومية جلسة سطح مكتب. إصدار macOS يحتاج macOS 14 أو أحدث. حزم Linux تستهدف التوزيعات الحديثة التي تستخدم glibc، وتختلف إمكانية فتح الملفات التنفيذية من مدير الملفات حسب التوزيعة. Windows ARM وAlpine بنظام musl خارج نطاق الحزم الجاهزة.

**إذا نزّلت المصدر**، افتح `Start.bat` على Windows أو `Start.command` على macOS أو `Start.sh` على Linux. يظهر التأكيد في نافذة الأوامر. يحتاج مشغّل المصدر على Linux إلى glibc 2.28 أو أحدث وأدوات `curl` و`tar` و`sha256sum` أو `shasum`. عند غياب أداة، يعرض المشغّل اسمها قبل التنزيل. قد تحتاج إلى منح صلاحية تشغيل الملف حسب مدير الملفات.

**لنشر إصدار على GitHub**، ارفع المصدر ثم ادفع وسم إصدار مثل `v2.0.1`. بعد اجتياز الاختبارات، يبني GitHub Actions الحزم ويرفقها مع بصماتها في مسودة ضمن **Releases**. راجعها واضغط **Publish release** لتصبح الحزم متاحة للتنزيل. يبقى المشغّل المبني محليًا في `dist` والأرشيفات في `packages`، وكلاهما خارج ملفات المصدر. [آلية إنشاء مسودة GitHub Release](https://cli.github.com/manual/gh_release_create).

يستخدم Mac بمعالج Intel إصدار ONNX Runtime الذي له [حزمة منشورة لـPython 3.12 على Intel](https://pypi.org/project/onnxruntime/1.23.2/#files). يختار المشغّل الإصدار المناسب للمنصة تلقائيًا من قفل التبعيات.

### أين يثبّت التطبيق والمحركات؟

| المكوّن | ما يحدث عند التجهيز |
|---|---|
| التطبيق وFaster Whisper الافتراضي | تُنشأ بيئة Python في `app-environment-v2` داخل مجلد بيانات المستخدم. يأتي Faster Whisper مع التبعيات الأساسية لتشغيل المحرك الافتراضي مباشرة. |
| المحركات الاختيارية المبنية على Python | زر **تثبيت المحرك** أو أول معالجة به يجهز بيئة منفصلة في `runtimes` لهذا المحرك، ويثبت حزمته وتبعياته ثم يختبر استيرادها. **إعادة تجهيز Faster Whisper** تستخدم أيضًا بيئة إصلاح منفصلة. |
| CrispASR وllama.cpp | يُنزّل التطبيق حزمة تنفيذية من إصدار المشروع الرسمي تناسب النظام والمعالج والبناء المطلوب، ويتحقق من بصمتها ويفكها داخل `runtimes`. تعمل كعملية محلية. |
| النماذج والتسريع | الأوزان ملفات مستقلة عن المحرك ويمكن إعادة استخدام ملفات موجودة. تعريفات البطاقة وملحقات النظام مثل CUDA/cuDNN تبقى متطلبات النظام بحسب المحرك؛ لا يثبّتها زر المحرك. |

التثبيت التلقائي لا يضيف محركًا إلى النظام ولا يحتاج صلاحية مدير. تبديل المحرك يغيّر النماذج والإعدادات المعروضة ولا يبدأ تثبيتًا بمجرد الاختيار.

### نقل المشروع

- **على الجهاز نفسه:** انقل المصدر أو ملف التشغيل، وابدأ من المكان الجديد. بيانات المستخدم والبيئة تبقيان في موقعهما. لا حاجة لنقل `.venv` أو `venv` داخل المصدر، حتى لو كان المجلد آتيًا من Arch.
- **إلى جهاز أو نظام آخر:** انقل المصدر أو استخدم حزمة النظام الهدف. شغّل المشغّل المناسب لكي يبني بيئته من جديد. بيئات Python تحتوي على مسارات خاصة بالجهاز، لذلك تُعاد إنشاؤها عند النقل بدل الاعتماد على نسخة منها. [دليل Python للبيئات الافتراضية](https://docs.python.org/3.12/library/venv.html#how-venvs-work).
- **لنقل الإعدادات والأوزان:** صدّر الإعدادات من تبويب الدليل، وانقل الأوزان التي تريدها إلى مجلد معروف ثم أضفه للبحث المحلي. راجع مسارات الملفات المخصصة بعد الاستيراد. إذا غيّرت `WHISPER_PRO_DATA_DIR`، يبدأ التطبيق من مجلد البيانات المحدد الجديد.

## الاستخدام

1. اختر Faster Whisper ونموذجًا صغيرًا. ابدأ بـCPU وINT8. للعربية اختر نموذجًا متعدد اللغات؛ اللاحقة `.en` تعني الإنجليزية فقط.
2. اختر ملفات من الجهاز أو ارفعها، ثم لغة الصوت وصيغ الإخراج.
3. راجع الإعدادات واضغط بدء المعالجة. يُجهز المحرك والنموذج المطلوبان فقط.
4. راجع النص والتوقيت، ثم احفظ النتائج أو عدل المقاطع وصدّر نسخة جديدة.

افتح قائمة المحركات ومرر المؤشر فوق **اسم أي محرك قبل اختياره** لشرح استخدامه وقيوده. كذلك يظهر شرح الإعداد عند المرور فوق اسمه أو التركيز عليه بلوحة المفاتيح، مع قيمة مقترحة للبداية. القيم المقترحة نقاط بداية؛ لا توجد قيمة مثالية لكل تسجيل.

تبويب **المحرك والنموذج** يعرض حالة تثبيت المحرك وزر تثبيته أو فحصه وإصلاحه، ثم كل نماذجه في قائمة قابلة للبحث والتصفية. لكل نموذج حجم ملفات التشغيل، وحالة التحميل، وزر اختيار، وزر تحميل عند غيابه أو تحديث عند ثبوت تحديثه. جميع عناصر الدليل المرفق الـ226 لها حجم محفوظ من بيانات المصدر؛ النماذج الجديدة التي لا يعلن مصدرها الحجم تعرض ذلك بوضوح. زر «فحص الأحجام والتحديثات» يحدث معلومات القائمة دون تنزيل الأوزان. الفحص الدوري يتحقق أيضًا من إصدارات النماذج المحملة ويكمل أحجام العناصر الجديدة.

## المحركات

| المحرك | نطاق الربط والقيود |
|---|---|
| Faster Whisper / CTranslate2 | CPU وNVIDIA وفق المكتبات المتاحة |
| CrispASR | عائلات متعددة، منها Whisper وParakeet وQwen وCanary؛ القدرات بحسب العائلة والبناء |
| whisper.cpp عبر pywhispercpp | الحزمة التلقائية CPU؛ البناء المخصص يحدد التسريع |
| OpenAI Whisper | التنفيذ المرجعي المحلي عبر PyTorch |
| Transformers ASR | نماذج متوافقة مع واجهة ASR الرسمية؛ لا يشغل كود مستودعات افتراضيًا |
| Qwen ASR | المحرك الأصلي مع السياق والدفعات؛ المحاذاة المستقلة لتحسين التوقيت |
| FunASR | SenseVoice وParaformer وفق لغة النموذج وتوافقه |
| NVIDIA NeMo | المحرك الأصلي على Linux؛ بعض الأوزان متاحة عبر CrispASR على Windows |
| MLX Whisper | Mac بمعالج Apple Silicon فقط |
| Vosk | نماذج Kaldi محلية حسب اللغة |
| WhisperX | دفعات ومحاذاة وتمييز متحدثين اختياري؛ بعض النماذج لها شروط وصول |
| Sherpa ONNX | Transducer وParaformer وWhisper وMoonshine عبر OfflineRecognizer |

يضم الدليل **226 عنصر ملفات فريدًا**، منها 3 للترجمة النصية. ليست 226 بنية تدريب مختلفة: الصيغة والتكميم المختلفان قد يحتاجان ملفات مستقلة. الملف المتوافق مع محركين يسجل بهوية مشتركة، ولا يفترض توافق كل ملف GGUF مع كل محرك. الإعدادات محفوظة لكل محرك ونموذج، وتتغير الأدوات الظاهرة بحسب القدرات المعلنة.

الاكتشاف من قائمة ناشرين معتمدين ومصادر رسمية؛ بعض الملفات تحويلات ينشرها مشروع المحرك، ويعرض المصدر والترخيص. يستخدم الفحص ملفات المستودع وبياناته لترشيح التوافق، ولا يثبت تشغيل كل نموذج مكتشف. العائلات ذات تعليمات جديدة قد تحتاج محولًا جديدًا. يمكن إضافة نموذج محلي أو مستودع لدى الناشرين المعروضين.

## النماذج والتحديثات

- يظهر التحميل عند غياب التثبيت، والإصلاح عند فقدان الملفات المسجلة أو اختلاف أحجامها.
- يظهر التحديث فقط عند اختلاف بصمات **ملفات التشغيل**؛ تعديل وصف المستودع وحده لا يعد تحديث أوزان.
- إذا لم يعلن المصدر بصمة أو فشل الاتصال، تعرض حالة غير معروفة بدل اختلاق تحديث.
- الفحص الدوري للمحرك النشط يكتشف نماذج للقائمة؛ فحص إصدار النموذج يقارن أوزانه. لا تثبت الأوزان ولا ترقي الأدوات تلقائيًا.
- يمكن تثبيت مراجعة محددة. تحفظ لقطات Hugging Face القديمة عند تحديث الأوزان؛ لا توجد واجهة استرجاع الإصدار السابق بعد.

التنزيل يدعم إعادة المحاولة والاستكمال عندما يؤكد الخادم تطابق الملف، والتحقق من البصمات حين يوفرها المصدر، وتقدمًا حسب البايتات. الملفات المشتركة تستخدم مخزنًا واحدًا وروابط صلبة إن دعمها النظام، مع نسخ بديل عند تعذرها.

## استخدام نماذج سبق تنزيلها

في تبويب **المحرك والنموذج** اضغط **«البحث عن نماذج موجودة في الجهاز»**. يبحث مرة واحدة لكل المحركات في مخازن Hugging Face وWhisper وModelScope وOllama وLM Studio والأماكن الشائعة. تظهر فقط نتائج المحرك المختار، وتتغير القائمة فور تبديله دون إعادة البحث. يمكن أن يظهر الملف نفسه مع أكثر من محرك متوافق دون نسخه لكل محرك. تظهر نماذج الترجمة النصية في تبويب **الإخراج والترجمة** بعد اختيار محرك الترجمة المناسب. من خيارات البحث يمكن إضافة مجلد مخصص أو توسيع البحث إلى الأقراص المحلية.

- **استخدام من مكانه:** يسجل النموذج دون تنزيله أو تغيير ملفات البرنامج الآخر. أبق مجلد المصدر في مكانه.
- **نسخ واستخدام:** ينشئ نسخة مستقلة في مخزن البرنامج، مع تقدم وإمكانية إلغاء؛ يترك الأصل كما هو.
- تُجمع المسارات المؤدية إلى الملفات نفسها، ويستخدم النموذج المعروف هويته الموجودة في الدليل. قد تظهر نسختان مستقلتان متطابقتا المحتوى؛ لا تُحسب بصمات جميع ملفات الجهاز أثناء البحث.
- البحث محدود بالوقت والمجلدات ويعرض عند عدم اكتماله. يتجاوز الملفات السحابية غير المتاحة محليًا، ولا يشغّل النموذج أو ينزّل أوزانًا أثناء البحث. التعرف على الصيغة لا يضمن توافق كل نموذج أو جودة ترجمة نموذج لغوي عام.

تظهر للحقول نافذة شرح واحدة عند المرور فوق اسم الإعداد أو التركيز عليه بلوحة المفاتيح. للنماذج المرتبطة بمصدر معروف يمكن فحص التحديثات؛ يبقى المصدر غير القابل للتحقق بلا ادعاء تحديث.

## الترجمة والإخراج

- SRT وVTT وASS وTXT وJSON وCSV، مع حماية النتائج الموجودة افتراضيًا.
- طول الأسطر وعددها ومدة العرض والإزاحة ومجلد الحفظ ومجلد مستقل لكل ملف اختياريًا.
- عند اختيار ASS تظهر إعدادات الخط والحجم والألوان والحد والظل والعريض والمائل والموضع والهوامش ودقة التصميم، وتطبق أيضًا عند إعادة تصدير المقاطع المعدلة.
- محاذاة إضافية عبر WhisperX أو Bournemouth Forced Aligner. تحسن موضع النص ولا تصحح الكلمات. إذا غاب توقيت بعض الكلمات يحفظ النص كاملًا.
- ترجمة محلية عبر Transformers أو llama.cpp، مع Hy-MT2 أو OPUS en-ar. السياق والقاموس والدفعات للنماذج الحوارية. OPUS en-ar مخصص للإنجليزية إلى العربية.
- تمييز متحدثين حسب المحرك، أو فصل قناتي ستيريو إلى مهمتين؛ لا يستنتج هوية الشخص.
- متابعة الوقت المستغرق والمتبقي التقديري ونسبة الإنجاز، وعرض حي للمقاطع في لوحة تمرير مستقلة. يدعم إيقاف المهمة مؤقتًا واستئنافها وتخطيها أو إلغاءها.
- سجل لكل ملف يعرض المدة والمحرك والنموذج وتاريخ ووقت المعالجة، مع محرر مقاطع وتصدير نسخة معدلة من قائمة المهام.
- PyAV لقراءة الصوت؛ التفريغ العادي لا يحتاج برنامج FFmpeg منفصلًا. **استخراج ترجمة نصية مضمنة يحتاج FFmpeg موجودًا على الجهاز**. مسارات الصور والنص المحروق على الفيديو يحتاجان OCR غير مدمج حاليًا.

التقسيم دون توقيت الكلمات تقريبي داخل زمن المقطع، ويعرض تنبيهًا عند استخدامه. مدة المقطع القصوى هدف للتقسيم وليست ضمانًا عند غياب حدود الكلمات. راجع النتائج قبل نشرها.

## البيانات والتوافق

تخزن البيانات في `%LOCALAPPDATA%\WhisperPro` على Windows، و`~/Library/Application Support/WhisperPro` على macOS، و`${XDG_DATA_HOME:-~/.local/share}/whisper-pro` على Linux. يمكن تغييرها عبر `WHISPER_PRO_DATA_DIR`. تشمل البيئة والنماذج والإعدادات والسجل ونسخ العمل والنتائج الافتراضية. تغيير مخزن النماذج لا ينقل الملفات القديمة تلقائيًا.

الاستدلال والترجمة محليان. تستخدم الشبكة لتجهيز الأدوات والنماذج وفحصها أو تنزيل الوسائط. رمز Hugging Face يبقى في الجلسة ولا يحفظ أو يصدر مع الإعدادات. وضع دون تنزيل يتطلب تجهيز جميع الموارد المطلوبة مسبقًا، ويُظهر خطأ عند فقدانها. ليس جدار حماية للنظام أو ضمانًا لسلوك ملف تنفيذي خارجي تختاره يدويًا.

البيئة الأساسية مقفلة في `uv.lock`. المحركات الاختيارية في بيئات منفصلة بإصدارات رئيسية محددة، وتسجل التبعيات المحلولة في `installed.lock.txt`. النماذج الكبيرة قد تحتاج ذاكرة ومساحة ومكتبات GPU إضافية. اختيار CUDA لا يثبت تعريف البطاقة. يمكن اختيار بيئة Python أو ملف محرك جاهز عند الحاجة.

## التحقق والتطوير

نجح تفريغ صوت إنجليزي فعلي على Windows CPU عبر Faster Whisper وCrispASR وpywhispercpp، بما في ذلك نماذج اكتُشفت محليًا واستُخدمت مباشرة أو نُسخت دون تنزيل. اجتاز المشروع 65 اختبارًا آليًا. بقية المحركات والمحاذاة والترجمة الكبيرة ربطت بناء على الواجهات الرسمية، وتحتاج تجربة أوزانها على أجهزتكم.

للمطور: `uv sync --locked`، ثم `uv run --locked pytest -q` و`uv run --locked ruff check core engine ui app.py launcher.py desktop_launcher.py build_release.py tests`. لبناء مشغل النظام الحالي: `uv run --locked python build_release.py`. يحتاج PyInstaller مشغلًا مستقلًا لكل نظام؛ لا ينشئ Windows وحده نسخة macOS مختبرة.
